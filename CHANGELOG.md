# Changelog

All notable changes to this project are documented here. The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and the project uses [Semantic Versioning](https://semver.org/).

## [Unreleased]

### Fixed
- A session that was open during the backup failed to upload (`corrupted on transfer: md5 hashes differ`) and stopped the whole run, so plans, history and the last-backup stamp were skipped too. Files changed in the last 24 hours are now copied into the stage as a fixed snapshot. A step that still fails no longer stops the others: the stamp records `failed_steps`, `doctor` warns about them, and the command exits with an error.
- `doctor` showed ✓ for the daily backup even when its last run had failed (`last exit code = 1`), because it only checked that the job was installed. It now warns when the last run exited non-zero, and when the job is scheduled but the last-backup stamp is more than 26 hours old.

## [0.1.1] - 2026-10-15

### Added
- Logo: a tree-ring mark with light and dark lockups and a social preview, generated by `assets/brand/make_logo.py`.
- Animated logo: the README header builds (the rings grow, the marker draws, the name types in) and replays every 10 s, with a static fallback for reduced motion; `intro.mp4` and `intro.gif` for posts.

### Fixed
- A restored session older than `cleanupPeriodDays` was deleted again by Claude Code's next cleanup, which goes by file date. Restored session files and plans are now dated to the moment of restore. Files already on the machine keep their date.

## [0.1.0] - 2026-10-14

### Added
- `init`, `backup`, `status` and `restore` (`list`, `session`, `project`, `memory`, `history`, `plans`) over any rclone remote.
- Archive layout: memory mirrored with removed or changed notes kept under `_deleted/<run>/`; sessions filed by start month and bundled with their subagents, tool results and file-history; plans and per-machine prompt history archived.
- Secret scanner (`scan`, plus a scan before every backup) covering nine common key and token formats; values are never shown. `--strict-secrets` and `secrets_on_found = abort` stop uploads of new findings.
- Google Drive sharing check after each backup, through rclone permission metadata.
- `doctor` health check.
- Daily schedule: launchd on macOS, systemd user timer on Linux.
- Claude Code plugin with a `/cc-chronicle` skill; `install.sh` for the CLI.
